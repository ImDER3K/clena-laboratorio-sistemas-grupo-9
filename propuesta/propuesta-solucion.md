# Propuesta de solución
**Pregunta**
**¿Qué se propone?**Un sistema de catalogación y búsqueda digital de los documentos históricos, que permita consultar su información básica (título, fecha, tema, ubicación física) sin manipular el original.
**¿Para quién?** Investigadores, estudiantes y visitantes que consultan el archivo (usuarios directos), y el personal que lo administra (responsables del proceso).
**¿Qué problema resuelve?**Hoy encontrar un documento depende de registros manuales y de la memoria del personal, lo que toma mucho tiempo y expone los documentos originales a desgaste o pérdida de información.
**¿Cómo funcionaría?**El personal registra cada documento en una base de datos con una ficha y una imagen digitalizada. El usuario busca por palabra clave, fecha o tema, ve la ficha y la copia digital, y solicita el original solo si lo necesita.
**¿Qué tecnología podría utilizarse?**Digitalización con escáner, una base de datos, una aplicación web de búsqueda y códigos QR en las cajas para ubicar cada documento.

> Opciones posibles: aplicación web, aplicación móvil, sistema de información, base de datos, código QR, sistema de búsqueda, inteligencia artificial, IoT, digitalización u otro mecanismo. No es necesario desarrollarla.

## Flujo básico de uso

l.personal registra y digitaliza: cada documento se escanea y se guarda con una ficha (título, fecha, tema, estado de conservación y ubicación física identificada con un código QR).
2.El usuario busca: desde un computador o un celular, escribe una palabra clave, fecha o tema y el sistema muestra las fichas y la copia digital.
3.Se consulta o se solicita el original: si la copia digital basta, la consulta termina ahí. Si necesita el original, lo solicita en el sistema y el personal lo ubica con el QR, dejando registro de quién lo consultó y cuándo.

## Beneficios esperados
-Se reduce el tiempo de búsqueda de un documento.
-Se protegen los originales, porque se manipulan menos.
-La información deja de depender de la memoria del personal.
-Queda un registro de quién consulta qué y cuándo.
-Se amplía el acceso para estudiantes e investigadores, incluso a distancia.
-Se facilita preservar la información si un documento se deteriora. 

## Riesgos o limitaciones

-La digitalización toma tiempo y requiere equipos (escáner) y personal capacitado.
-Hace falta presupuesto para infraestructura y mantenimiento.
-Algunos documentos pueden tener restricciones de acceso o derechos que impidan publicarlos.
-La información digital necesita copias de seguridad y control de acceso para evitar pérdidas o usos indebidos.
-El personal y los usuarios deben aceptar y aprender a usar el nuevo sistema.
-La conectividad puede ser limitada en el lugar.


## Alternativas consideradas
**Mantener el registro manual y solo ordenarlo mejor:** se descartó porque mejora un poco, pero no elimina la dependencia de las personas ni reduce el desgaste de los originales.
**Aplicación móvil únicamente:** se descartó porque la consulta es más cómoda en computador, y una app no resuelve por sí sola el registro y la digitalización de la información.
**Digitalizar los documentos sin sistema de búsqueda:** se descartó porque las imágenes quedarían guardadas pero sin una forma práctica de encontrarlas.
Inteligencia artificial para transcribir y clasificar todo: se descartó para una primera etapa porque es costosa y compleja; se deja como mejora posterior.
