# Problemas identificados 

Espacio observado: Biblioteca del CLENA.

Problema 1: Los usuarios no saben usar el software de consulta de la biblioteca

Espacio: Biblioteca.

Usuario: Visitantes, estudiantes e investigadores que consultan el catálogo, y el personal de la biblioteca que les ayuda.

Situación: Durante la visita se observó que los usuarios deben utilizar un software para buscar o consultar material de la biblioteca, pero tienen dificultades para manejarlo.

Problema: El software es antiguo y poco intuitivo, por lo que los usuarios no comprenden cómo usarlo sin ayuda.

Impacto: Los usuarios pierden tiempo, pueden desistir de la consulta, no aprovechan los recursos de la biblioteca y el personal debe dedicar tiempo a explicar el uso una y otra vez.

Oportunidad tecnológica: Una interfaz moderna e intuitiva para consultar el catálogo, con búsqueda sencilla, instrucciones claras en pantalla y acceso desde computador o celular.

Problema 2: Dependencia del personal para resolver las consultas

Espacio: Biblioteca.

Usuario: Personal de la biblioteca y usuarios que consultan material.

Situación: Cuando el usuario no logra usar el software, recurre al personal para que haga la búsqueda por él.

Problema: Las consultas dependen de que haya alguien disponible que conozca el sistema, y no existe una forma de que el usuario sea autónomo.

Impacto: Se sobrecarga al personal, se generan esperas y se reduce el tiempo para otras tareas de la biblioteca.

Oportunidad tecnológica: Un sistema de búsqueda de autoservicio con ayudas guiadas, que reduzca la necesidad de acompañamiento.

Problema 3: Falta de orientación visible para usar el sistema

Espacio: Biblioteca.

Usuario: Visitantes y usuarios nuevos.

Situación: Quien llega por primera vez no encuentra instrucciones claras sobre cómo consultar el catálogo.

Problema: No hay señalización ni guías visibles que expliquen los pasos para buscar material.

Impacto: Los usuarios nuevos se sienten perdidos y es menos probable que vuelvan a usar la biblioteca.

Oportunidad tecnológica: Guías digitales en pantalla, tutoriales cortos y códigos QR en los equipos que lleven a instrucciones paso a paso.

Criterio de selección

Para escoger cuál trabajar se comparan los tres problemas según cuatro preguntas: qué tan importante es para los usuarios, cuánta evidencia se tiene, qué tan viable es abordarlo con tecnología y qué tanto se comprendió con lo observado en la visita.

Se selecciona el Problema 1, porque es el que se observó directamente, afecta a todos los usuarios que consultan el catálogo y es el origen de los otros dos: si el software fuera claro y fácil de usar, disminuiría la dependencia del personal y la necesidad de orientación adicional.
