# HU-05: Abrir el catálogo escaneando un QR

## Descripción
Como usuario que llega con su teléfono celular a la biblioteca, quiero escanear un código QR ubicado en la entrada o salas, para abrir directamente el catálogo web sin necesidad de teclear direcciones web.

## Criterios de Aceptación
1. Disponibilidad de un código QR físico en el CLENA que enlace directamente a la aplicación web de consulta.
2. La aplicación web debe cargar correctamente y optimizarse para dispositivos móviles al escanear el QR.
