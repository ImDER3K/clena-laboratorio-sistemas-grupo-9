# HU-06: Ver disponibilidad del libro

## Descripción
Como usuario de la biblioteca, quiero saber si un libro se encuentra disponible en la estantería o si está prestado/en consulta, para no buscar un ejemplar que no está accesible en el momento.

## Criterios de Aceptación
1. Cada libro en los resultados de búsqueda debe mostrar un indicador de estado (Disponible, Prestado, En mantenimiento).
2. El indicador debe tener códigos de color claros (ej. verde para disponible, rojo/naranja para no disponible).
