# HU-07: Mensaje claro si no hay resultados

## Descripción
Como usuario de la biblioteca, quiero recibir un mensaje claro y sugerencias útiles cuando mi búsqueda no arroje resultados, para saber qué hacer a continuación sin sentirme perdido.

## Criterios de Aceptación
1. Si la búsqueda no encuentra coincidencias, mostrar un mensaje amigable (ej. "No encontramos libros con ese término").
2. Proveer sugerencias como revisar ortografía, usar términos más generales o contactar al bibliotecario.
