# HU-10: Registrar un libro nuevo

## Descripción
Como bibliotecario, quiero registrar un libro nuevo en el sistema ingresando sus datos principales (título, autor, categoría, ubicación), para mantener el catálogo actualizado.

## Criterios de Aceptación
1. Formulario de registro con campos obligatorios validados (Título, Autor, Sala, Estante).
2. Guardado exitoso en la base de datos y confirmación visual en pantalla.
